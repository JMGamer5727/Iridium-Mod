Iridium Mod - first item additions (Minecraft 26.3 / Fabric)

Upload these files into the matching paths in your existing repository.
Replace IridiumMod.java with the included version and add ModItems.java.
Add the included lang, item model, client item definition, and PNG texture files.

This step registers Raw Iridium and Iridium Ingot in the Ingredients creative tab.
It does not yet add ore generation, crafting recipes, or the Iridium Block.
